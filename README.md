# AmazingSQL

**AmazingSQL** is an interactive platform to practice SQL by solving real-world questions in a friendly, gamified environment.

🌐 **Try it live:** [amazingsql.up.railway.app](https://amazingsql.up.railway.app/)

***

## Features

- 🧑‍💻 Practice SQL queries on a variety of curated problems
- 🏆 Track your progress through user authentication (Firebase)
- ⚡ Instant feedback and grading for each submission
- 🎮 Gamified interface encourages learning and improvement

***

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask)
- **Database:** Problems and scoring tracked with Firebase
- **Other:** Dockerfile for deployment

***

## Getting Started

1. **Clone the repo:**
    ```bash
    git clone https://github.com/bowale-os/AmazingSQL.git
    cd AmazingSQL
    ```

2. **Install packages:**
    ```bash
    pip install -r requirements.txt
    ```

3. **Run the app locally:**
    ```bash
    python app.py
    ```
   The app will be available at `http://localhost:5000`
